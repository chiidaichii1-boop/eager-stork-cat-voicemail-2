Entry for the make.fun bounty [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443).

`main.py` (Python standard library only) writes one line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — the voicemail greeting a cat would
record:

> You've reached the cat. I knocked your mug off the table, then napped on the evidence. Leave a message after the beep.

The greeting is 118 characters, deterministic, and written from scratch
for this bounty.
